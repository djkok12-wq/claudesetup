## 10. 시뮬레이터 설계 (기술 문서)

### 10.1 아키텍처

```
simulator/
├─ index.html        ← 빌드 결과물 (단일 파일, 브라우저에서 바로 실행)
├─ build.py          ← src/ 조각을 index.html 로 번들
└─ src/
   ├─ data.js        ← 평면(실·개구부 mm 좌표), 발코니별 확장 플래그, 마감재 카탈로그 23항목, 컨셉 5종, 견적 기준
   ├─ furniture.js   ← 가구 28종 모델·기본 배치·충돌 판정(OBB·SAT)
   ├─ textures.js    ← 절차적 텍스처: 마루(일반·헤링본), 타일(대리석·트래버틴·테라조·콘크리트), 헥사곤, 서브웨이, 템바, 무늬목, 라임워시
   ├─ scene.js       ← Three.js: 실 사각형에서 벽 자동 생성, 개구부 차감, 외벽 판정, 도어·창호·중문, 가구, 조명, 워크스루
   ├─ ui.js          ← 컨셉·마감재·견적·기획서 패널
   ├─ shell.html / style.css
```

### 10.2 핵심 설계 결정

| 결정 | 이유 |
|---|---|
| 실(Room) 사각형 + 개구부(Opening) 선분으로 평면 정의 | 도면 치수를 그대로 옮길 수 있고, 구조 옵션(확장·드레스룸)을 데이터만 바꿔 재생성할 수 있어요 |
| 벽을 '실별 반쪽 벽'으로 생성 | 같은 벽의 양면에 서로 다른 마감(거실 아트월 / 안방 벽지)을 독립적으로 입힐 수 있어요 |
| 슬롯(Slot)별 공유 재질 | 자재를 바꾸면 해당 슬롯의 모든 면이 즉시 바뀌어요(재빌드 없음) |
| 월드 좌표 UV(미터 단위) | 타일·마루 패턴이 실제 크기(예: 600×1200)로 표시되고 면끼리 이어져요 |
| 절차적 텍스처(캔버스) | 외부 이미지 없이 단일 HTML로 배포할 수 있고, 저작권 문제가 없어요 |
| 3D 모델 → 물량 자동 산출 | 바닥·벽 면적, 걸레받이 길이, 도어 수, 가구 길이를 모델에서 바로 계산해 견적과 연동해요 |

### 10.3 사용법

1. `simulator/index.html`을 브라우저에서 엽니다(인터넷 연결 필요: Three.js CDN).
2. **컨셉·옵션** 탭에서 컨셉을 고르고, 드레스룸·확장·샷시·간접조명 옵션과 조명 모드를 정해요.
3. 3D 화면에서 벽·바닥·가구를 탭하면 **마감재** 탭의 해당 항목으로 이동해요. 자재를 고르면 바로 반영돼요.
4. **워크스루**: 드래그로 둘러보고 W/A/S/D(모바일은 화면 버튼)로 이동해요. 왼쪽 아래 메뉴로 방을 바로 옮길 수 있어요. 주간 모드에서 계절·시각을 바꾸면 창으로 드는 햇빛이 바뀌어요.
4-1. **발코니 확장**: 컨셉·옵션 탭에서 4곳을 따로 켜고, 상단 '↔ 확장 전/후'로 화면을 나눠 비교해요.
4-2. **가구 배치**: 가구 배치 탭에서 추가 → 3D에서 탭해 선택 → 끌어서 이동. 도구막대로 회전·복제·삭제·색상을 바꿔요. 빨간 테두리는 벽·붙박이장·문 열림과 간섭이 있다는 뜻이에요.
5. **견적** 탭에서 '견적표 복사'를 누르고 엑셀에 붙여넣어 업체 견적과 비교해요.
6. 수정 후 `python3 simulator/build.py`로 다시 빌드해요.

- 다용도실은 세탁·보일러·대피공간 기능 때문에 확장 대상에서 뺐어요.

### 11.5 아키텍처 변경

```
src/furniture.js   ← 신규: 가구 라이브러리·모델·기본 배치·충돌(OBB·SAT)
src/scene.js       ← 빌드를 '변형(Variant)' 단위로 분리 → 현재안/확장 전 두 장면을 동시에 만들어 가위(scissor) 분할 렌더
                     태양 위치 계산, 실외 환경, GTAO 컴포저, 가구 선택·드래그·키보드 조작
src/data.js        ← 발코니별 확장 플래그(exp.living/master/bed2/bed3), 커튼 항목, 확장 공사비
```

- 충돌 검사는 가구를 회전 사각형(OBB)으로 보고, 벽·붙박이·문 열림 영역(빌드 때 자동 수집)과 분리축 정리(SAT)로 판정해요.
- 비교 모드는 두 변형을 같은 장면에 두고, 프레임마다 왼쪽·오른쪽을 각각 한 변형만 보이게 해서 그려요.
