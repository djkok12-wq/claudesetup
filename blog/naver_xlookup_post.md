## 2. 본문

엑셀에서 "다른 표에 있는 값 가져오기"를 할 때 가장 많이 쓰는 함수가 VLOOKUP이에요. 그런데 VLOOKUP은 쓰다 보면 꼭 한 번씩 막히는 지점이 있어요. 찾는 값이 왼쪽에 있으면 못 쓰고, 열 번호를 숫자로 세어 넣어야 하고, 열을 하나 끼워 넣으면 결과가 틀어져요.

### 2. XLOOKUP 함수 구조

```
=XLOOKUP(찾을값, 찾을범위, 반환범위, [없을때값], [일치방식], [검색방향])
```

| 순서 | 인수 | 필수 | 설명 |
|---|---|---|---|
| 1 | 찾을값 (lookup_value) | 필수 | 무엇을 찾을지 |
| 2 | 찾을범위 (lookup_array) | 필수 | 어느 열(또는 행)에서 찾을지 |
| 3 | 반환범위 (return_array) | 필수 | 찾았을 때 어느 열의 값을 가져올지 |
| 4 | 없을때값 (if_not_found) | 선택 | 못 찾으면 보여줄 값. 생략 시 #N/A |
| 5 | 일치방식 (match_mode) | 선택 | 0 정확히(기본), -1 작은값 근사, 1 큰값 근사, 2 와일드카드 |
| 6 | 검색방향 (search_mode) | 선택 | 1 위→아래(기본), -1 아래→위, 2/-2 이진검색 |

처음 세 개만 알아도 80%는 해결돼요. 4~6번은 뒤의 예제에서 하나씩 써 볼게요.

### 3. VLOOKUP과 무엇이 다른가

| 비교 항목 | VLOOKUP | XLOOKUP |
|---|---|---|
| 왼쪽 열 값 가져오기 | ❌ 불가 | ✅ 가능 |
| 반환 열 지정 방식 | 열 번호(숫자) | 범위 직접 지정 |
| 열 삽입/삭제 시 | 결과 틀어짐 | 영향 없음 |
| 기본 일치 방식 | 근사치(TRUE) | 정확히 일치 |
| 못 찾았을 때 처리 | IFERROR 따로 필요 | 함수 안에서 처리 |
| 여러 열 한 번에 반환 | ❌ | ✅ (동적 배열) |
| 마지막 값 찾기 | 어려움 | 검색방향 -1로 해결 |
| 가로 방향 찾기 | HLOOKUP 별도 | 같은 함수로 가능 |

한 줄로 요약하면, **VLOOKUP의 단점을 전부 지우고 HLOOKUP·INDEX/MATCH 역할까지 합친 함수**예요.

### 4. 실무 예제 9가지

아래 예제는 모두 A열 사원번호, B열 이름, C열 부서, D열 연봉이 2행부터 100행까지 있는 '직원 명단' 시트를 기준으로 할게요.

**예제 1. 기본 조회 — 사원번호로 이름 찾기**

```
=XLOOKUP(F2, A2:A100, B2:B100)
```
F2에 입력한 사원번호를 A열에서 찾아 같은 행의 B열(이름)을 가져와요. VLOOKUP처럼 열 번호를 세지 않아도 돼요.

**예제 2. 못 찾았을 때 메시지 넣기**

```
=XLOOKUP(F2, A2:A100, B2:B100, "미등록")
```
VLOOKUP은 IFERROR로 감싸야 했지만, XLOOKUP은 4번째 인수에 바로 넣으면 끝이에요.

**예제 3. 왼쪽 열 값 가져오기 (VLOOKUP 불가)**

```
=XLOOKUP(F2, B2:B100, A2:A100)
```
이름(B열)으로 사원번호(A열)를 찾아요. 찾을범위와 반환범위를 바꿔 주기만 하면 방향 제한이 없어요.

**예제 4. 여러 열을 한 번에 가져오기**

```
=XLOOKUP(F2, A2:A100, B2:D100)
```
반환범위를 B:D 세 열로 잡으면 이름·부서·연봉이 옆 셀로 자동 펼쳐져요(동적 배열). 수식 하나로 세 칸이 채워지니 복사·붙여넣기 실수가 줄어요.

**예제 5. 구간별 요율 찾기 (근사치 -1)**

매출 구간표가 H열(하한)과 I열(수수료율)에 있을 때:
```
=XLOOKUP(G2, H2:H6, I2:I6, , -1)
```
일치방식 -1은 "정확히 일치하는 값이 없으면 그보다 작은 값 중 가장 가까운 값"을 찾아요. VLOOKUP의 TRUE 근사치와 달리 **데이터를 정렬하지 않아도 돼요**.

**예제 6. 가장 최근(마지막) 거래 찾기 (검색방향 -1)**

거래 내역이 날짜순으로 쌓여 있을 때 특정 고객의 마지막 거래일:
```
=XLOOKUP(F2, 고객열, 날짜열, "거래없음", 0, -1)
```
검색방향 -1은 아래에서 위로 찾기 때문에, 중복된 값 중 **가장 마지막 행**을 가져와요. VLOOKUP으로는 꽤 번거로웠던 작업이에요.

**예제 7. 일부 글자만 알 때 (와일드카드 2)**

```
=XLOOKUP("*전자*", B2:B100, A2:A100, "없음", 2)
```
일치방식 2를 지정하면 `*`(아무 글자 여러 개), `?`(한 글자)를 쓸 수 있어요. 거래처명이 "삼성전자", "LG전자"처럼 일부만 기억날 때 유용해요.

**예제 8. 조건 두 개로 찾기 (다중 조건)**

부서가 G2이고 이름이 H2인 사람의 연봉:
```
=XLOOKUP(1, (C2:C100=G2)*(B2:B100=H2), D2:D100, "해당없음")
```
두 조건을 곱하면 둘 다 참인 행만 1이 되고, 그 1을 찾는 원리예요. 기존에는 보조 열을 만들어야 했던 작업이에요.

**예제 9. 가로·세로 교차 조회 (XLOOKUP 중첩)**

월별(1행)·제품별(A열) 매출표에서 특정 제품의 특정 월 값:
```
=XLOOKUP(G2, A2:A20, XLOOKUP(H2, B1:M1, B2:M20))
```
안쪽 XLOOKUP이 해당 월의 열 전체를 반환하고, 바깥 XLOOKUP이 그 열에서 제품 행을 찾아요. INDEX/MATCH/MATCH 조합을 한 함수로 대체할 수 있어요.

### 5. 자주 나는 오류와 해결법

| 오류 | 원인 | 해결 |
|---|---|---|
| #NAME? | Excel 2019 이하에서 열었거나 함수명 오타 | 버전 확인, 구버전 공유 시 INDEX/MATCH로 변환 |
| #N/A | 찾는 값이 없음 | 4번째 인수에 대체 문구 지정 |
| #VALUE! | 찾을범위와 반환범위의 행 수가 다름 | 두 범위를 같은 행 개수로 맞추기 |
| #SPILL! | 여러 열 반환 시 옆 셀에 이미 값이 있음 | 결과가 펼쳐질 칸 비우기 |
| 숫자인데 못 찾음 | 한쪽은 숫자, 한쪽은 텍스트 형식 | VALUE 함수나 '텍스트 나누기'로 형식 통일 |

**실무 팁 3가지**
- 범위는 A:A처럼 열 전체보다 **A2:A100처럼 범위를 지정**하거나, 표(Ctrl+T)로 만들어 `표1[사원번호]`처럼 쓰는 게 빠르고 안전해요.
- 다른 사람과 공유하는 파일이라면 **받는 사람의 엑셀 버전**을 먼저 확인하세요.
- VLOOKUP으로 짜 둔 기존 수식을 전부 바꿀 필요는 없어요. 새로 만드는 표부터 XLOOKUP을 쓰면 충분해요.

### 6. 정리

XLOOKUP은 "찾을값, 찾을범위, 반환범위" 세 가지만 기억하면 바로 쓸 수 있어요. 여기에 못 찾았을 때 문구, 근사치, 역방향 검색, 와일드카드 옵션을 더하면 VLOOKUP·HLOOKUP·INDEX/MATCH가 하던 일을 거의 다 대체할 수 있어요.

Excel 2021 이상이나 Microsoft 365를 쓰고 있다면 오늘 다룬 예제 1번부터 하나씩 따라 해 보세요. 특히 **예제 4(여러 열 반환)**와 **예제 6(마지막 값 찾기)**은 한 번 써 보면 VLOOKUP으로 돌아가기 어려울 거예요.

다음 글에서는 XLOOKUP과 함께 쓰면 좋은 FILTER, UNIQUE 함수를 다뤄 볼게요. 궁금한 점은 댓글로 남겨 주세요.
